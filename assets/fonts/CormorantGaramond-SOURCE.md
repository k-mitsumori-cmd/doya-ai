# Cormorant Garamond

- Upstream: Google Fonts, `ofl/cormorantgaramond/CormorantGaramond[wght].ttf`
- Immutable revision: `3dd78844021e948ceb633d1dcee3f7885561b5d9`
- Source: https://github.com/google/fonts/tree/3dd78844021e948ceb633d1dcee3f7885561b5d9/ofl/cormorantgaramond
- License: `OFL-CormorantGaramond.txt` (SIL Open Font License 1.1, copyright notice included)
- The complete variable font was compressed to WOFF2 with fontTools. No glyph subsetting or design changes. The character map, advance metrics and weight axis were verified after conversion.
- Used by the existing Mitsuboshi layout at weights 400 and 600. The existing CSS variable, swap behavior and serif fallback family are retained.

This font is local so that its build does not depend on the URL shape in a Google Fonts CSS response. Other font families are unchanged.
