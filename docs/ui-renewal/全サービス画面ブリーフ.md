# 全サービス作業画面（オーロラ基調）作成ブリーフ

リポジトリ: /Users/mitsumori_katsuki/Code/09_Cursol-ui-renewal （ブランチ feat/ui-renewal-sample）
見本ページ: http://localhost:3477/ui-renewal?s=<サービスID> で各画面を直接開ける（デザイン案は既定でオーロラ）。

## 目的
ドヤAIの「UIリニューアル案（見本）」で、まだ画面が無い16サービスの作業画面を作る。
オーロラ案（流れるグラデーション・すりガラス・発光）で、見やすく、モダンな動きが盛りだくさんで「めっちゃいけてる」こと。
見本なので生成APIやDBは一切呼ばない。進行はタイマーで再現し、数字や結果はすべて見本データ。

## 触ってよいファイル（厳守）
- `src/app/ui-renewal/tools/<id>.tsx` と `src/app/ui-renewal/tools/<id>.module.css`（自分の担当IDのみ）
- それ以外（kit.tsx / kit.module.css / registry.tsx / RenewalApp.tsx / renewal.module.css / data.ts / 他の担当のファイル）は**編集禁止**。kit に足りない部品は自分の <id>.module.css / <id>.tsx の中に作る。
- 新しい npm パッケージは入れない。git commit はしない（リードがまとめて行う）。`next build` は走らせない（他の担当と衝突する）。

## 各ファイルの形
- `<id>.tsx` は `'use client'`、**default export の props なしコンポーネント**（既に仮置きファイルがあるので、Edit で中身を置き換える。削除→再作成は禁止）。
- 最外は `<div className={rs.tool}>`（`import rs from '../renewal.module.css'`）。
- 構成の基本：
  1. `<ServiceHero serviceId catchCopy points stats />` … 上部のオーロラ帯。catchCopy は短い日本語の大見出し、points はできること3つ、stats は見本の数字2つ。
  2. `<Steps steps={[...4つ前後]} current={n} />` … 工程バー。
  3. `<Workbench form={入力パネル}>{キャンバス}</Workbench>` … 左に入力、右に結果。表やボードが主役のサービス（営業管理・勤怠・プロマネ・HR など）は Workbench を使わず、全幅のダッシュボード構成にしてよい。
  4. キャンバスは `useRun(STEPS)` の phase で切り替え: `input` → `<IdleCanvas>`、`run` → `<RunStage>`、`done` → そのサービス固有の結果画面（ここが一番の見せ場）。
- kit（`./kit`）にある部品: useRun, ServiceHero, Steps, Workbench, Panel, Field, TextInput, TextArea, ChipSelect, ChipMulti, Slider, Toggle, RunButton, GhostButton, IdleCanvas, RunStage, Shimmer, ResultHead, Burst, Stagger, StaggerItem, Glass, GlowBorder, TiltCard, Typewriter, Marquee, Tabs, StatTile, Sparkline, Bars, Meter, Badge, Sheet, useFlash, NextLink, stageOf。使い方は kit.tsx を読むこと。
- 既存の動き部品 `../motion`（CountUp, Ring, Odometer, SplitText）、`framer-motion`（motion, AnimatePresence, layoutId, Reorder, drag など）、`lucide-react` アイコンも自由に使ってよい。
- 色は `var(--ink) var(--sub) var(--muted) var(--line) var(--paper) var(--card-bg) var(--card-border) var(--card-shadow) var(--card-blur) var(--accent-grad) var(--grad-text) var(--track) var(--r) var(--r-sm) var(--ease) var(--mono)` などの変数を使う。オーロラで最も映えるようにしつつ、他の3案（クリア／ミッドナイト＝暗い背景／ポップ）でも文字が読めて崩れないこと。固定の白背景・黒文字を直書きしない。
- 見本ギャラリー用画像は既存のものだけ: `/banner-samples/cat-{food,beauty,it,realestate,education,recruit,ec,finance,health,marketing,telecom,other}.webp`、`/banner-samples/purpose-{sns_ad,display,campaign,lp_hero,webinar,email,youtube}.webp`、`/doyaslide/template-covers/01-minimal-isometric.webp` 〜 `20-accessible-universal.webp`（ファイル名は data.ts の TASTES 参照）、キャラクター `/character/{hello,point,thinking,present,success,jump,love,focus,surprise}-256.webp`、マスコット `mascotOf(id)`（data.ts）。

## 「アクション盛り盛り」の目安（各画面で最低5つ以上）
例: ドラッグで並べ替え（framer-motion Reorder / drag）、カーソルで傾くカード（TiltCard）、回る光の縁（GlowBorder でおすすめを強調）、数字のカウントアップ、線が引かれるグラフ（Sparkline）、伸びる棒（Bars/Meter）、タイプライターで文章が出る、チャットの吹き出しが順に出る、layoutId でタブや選択が滑る、AnimatePresence で項目の追加・削除、ホバーで詳細が広がる、Sheet で詳細や書き出し、useFlash で「コピーしました」、マーキーで流れる帯、完了時の Burst。
動きは prefers-reduced-motion で止まるようにする（自分の CSS の @keyframes も @media (prefers-reduced-motion: reduce) で止める）。

## 文言のルール
- UI テキストはすべて日本語。丁寧だが短く、専門用語は避けて平易に。
- **絵文字は一切使わない**（アイコンは lucide-react）。
- 数字・企業名・人名はすべて架空の見本（実在企業名を使わない）。サービス名は `getServiceById(id)?.name`（`@/lib/services`）から取る。サービスの機能説明は services.ts の description / longDescription に沿う（存在しない機能を大きく謳わない）。
- 実データ・個人情報は使わない。

## 品質の条件
- スマホ幅 375px で横スクロールが出ない（表は横スクロール枠に入れるか、カード型に切り替える）。
- `npx tsc --noEmit -p .` で自分のファイルにエラーが無いこと（出力を `grep ui-renewal/tools/<id>` で絞る）。
- ブラウザで http://localhost:3477/ui-renewal?s=<id> を開き、入力→実行→結果まで操作して、コンソールエラーが無いことを確認（Claude Browser の mcp__Claude_Browser__* ツールが使えるなら使う。使えなければ型チェックまででよい）。
- 完了報告には、担当IDごとに「結果画面の見せ場」「入れた動き」「確認したこと／できなかったこと」を短く書く。
