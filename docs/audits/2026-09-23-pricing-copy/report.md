# 共通料金ページの利用上限表現

- 共通料金カードは `src/lib/services.ts` の文言を表示するため、ドヤインタビューの無料・PRO枠を「記事の生成・再生成の合計5回/日・30回/日」と明記した。
- ドヤインタビューのファイル説明にあった「5GB超」は実際の最大値と合わないため、プランに応じた最大5GBに修正した。
- 統一PROの共通料金カードと個別ページで、上限付きの機能を「使い放題」と表現していた箇所を「全サービスのプロ機能を利用可能」に変更した。各サービスの上限表示は残した。
- `verify-service-limit-ui.cjs`、`verify-active-service-navigation.cjs`、型検査、対象ファイルの ESLint を確認した。
