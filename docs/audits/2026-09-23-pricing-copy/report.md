# 料金・上限案内の表示整合性（2026-09-23）

## 修正した不一致

- バナー料金定義の無料枠に「ゲスト月3枚」と残っていたが、実際の `guestLimit` は0で生成にはログインが必要。
- バナーのURL生成画面と設定画面は、未ログイン時に「月0枚」、LIGHT利用者にPROの月150枚など、利用者の状態と違う案内を表示していた。
- SEOとバナーの料金ページ向けメタ説明文は、ゲスト利用や日次制限を誤記し、PROの枚数・回数にLIGHTの月額料金を組み合わせていた。JSON-LDの無料枠説明も同じ誤記だった。
- オープニングAIのメタ説明文は月額2,980円と記載していたが、サービス定義のPRO料金は9,980円。
- ペルソナの無料プラン説明にゲスト利用が可能と残り、LIGHTの生成枠も実際の日30回に対して15回と記載していた。
- 公開ページを取得して再確認したところ、サブページ用メタデータ関数が説明文を計算しても最終メタデータに渡さず、親LPの説明文を使っていた。この共通関数を修正し、HTML・OG・Twitterにページ固有の説明文が反映されるようにした。

## 検証

実際に生成されるSEO・バナー・オープニングのメタ説明文とJSON-LD、無料プランの案内文をコードから読み出し、上限単位と料金を照合した。ページ固有の説明文がHTML・OG・Twitterに共通して入る回帰テストを追加し、型チェック・Lint・本番ビルドで他画面への影響を検査する。認証後の課金画面を本番アカウントで操作する検査はしていない。

## ドヤインタビューと共通料金カードの追加確認

- 共通料金カードは `src/lib/services.ts` の文言を表示するため、ドヤインタビューの無料・PRO枠を「記事の生成・再生成の合計5回/日・30回/日」と明記した。
- ドヤインタビューのファイル説明にあった「5GB超」は実際の最大値と合わないため、プランに応じた最大5GBに修正した。
- 統一PROの共通料金カードと個別ページで、上限付きの機能を「使い放題」と表現していた箇所を「全サービスのプロ機能を利用可能」に変更した。各サービスの上限表示は残した。
- `verify-service-limit-ui.cjs`、`verify-active-service-navigation.cjs`、型検査、対象ファイルの ESLint を確認した。
- 共通プランの販促・総合料金ページ・メタ説明にも残っていた「使い放題」を上限付きの実際の契約内容に合わせた。
- ドヤインタビューのサイドバーに残っていた「無料登録で1時間使い放題」と終了モーダルは、記事生成APIの枠と一致しないため撤去し、無料登録で記事生成1日5回と表示した。
- 追加巡回で、ドヤバナーの紹介画面とサービス定義に「ゲストも1日1回」と残っていた。生成APIは未ログインのリクエストを401で拒否するため、紹介画面を「無料登録で月15枚」に、サービス定義をログイン必須に修正した。`verify-service-limit-ui.cjs`、`verify-active-service-navigation.cjs`、対象ESLintで確認した。
