# インタビュー一覧の障害表示（2026-09-23）

## 確認した問題

- DB接続設定がない場合、プロジェクト一覧とスキル一覧のGET APIが `success: true` の空配列を返していた。接続障害を「まだ何も作っていない」と誤認させる。
- 一覧を使う複数画面でも、取得失敗を空一覧や非表示として扱っていた。プロジェクト一覧画面・トップの最近のプロジェクト・スキル一覧・記事生成前のスキル選択画面で影響する。

## 補修と検証

- DB未設定時は両APIが503を返し、DB例外の詳細をレスポンスへ出さない。
- 利用画面はHTTP失敗・不正応答を空配列と区別し、再試行または再読み込み可能な案内を表示する。
- オフライン回帰で「正常な0件は200・接続なしは503」を両APIで確認。型チェックと対象ファイルのLintを実施。

## 別途確認中

- インタビューの表示上限「無料1日5回／PRO 30回」は、ユーザー確認により記事の新規生成・再生成を各1回と数える。現状のプロジェクト作成数チェックと記事生成経路をこの定義へ合わせる必要がある。本補修とは別の作業として追跡する。
