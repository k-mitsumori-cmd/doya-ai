# 公開サービス導線の照合（2026-09-23）

`getActiveServices()` に登録された17サービスについて、`href`、`dashboardHref`、`pricingHref`、`guideHref` の68個の定義を調べた。重複を除く38個のローカルパスすべてに画面ファイルが存在することを確認した。

本番の `/banner/guide` はHTTP 404だった。サービス定義には同URLが入っていたため、使い方ガイドのページを追加し、ランディングページからのリンクとサイトマップを更新した。ローカルでデスクトップ・スマートフォン表示はいずれもHTTP 200、見出し・4つのリンク・横はみ出しなし・ブラウザーエラーなしを確認した。

`verify-active-service-navigation.cjs` を標準の回帰テストに追加した。今後、アクティブなサービスの公開・ダッシュボード・料金・ガイド導線が存在しないページを指した場合はCIで検出する。

別途、アプリと共通コンポーネントにあるリテラルな内部 `href` を走査した。直接パスに画面がない候補は `/nagusame` と `/nagusame/pricing` のみで、どちらもルートグループ `(mitsuboshi)` 内に実在する画面だった。この走査ではテンプレート文字列などの動的リンクは対象外。

この検査は定義済みURLとページの存在、および追加ページの未ログイン表示を対象とする。認証後の操作、プラン権限、生成・保存の全経路が正常であることまでは証明しない。
