# ドヤペルソナ：画像再生成の画面導線

状態: 修正をローカル実装。CI・本番反映・実アカウントでの生成操作は未確認。

## 見つけた問題

- サーバーは画像の `regenerate` を受け付け、追加画像・再生成を無料5枚／有料30枚の日次枠で計上する。一方、成功済みのポートレートとシーン画像には画面上の再生成ボタンがなく、利用者が機能を使えなかった。
- シーン画像の再生成が失敗しても、画像が存在する表示分岐がエラー表示より先に返るため、失敗理由を見られなかった。

## 修正と確認範囲

- 成功済みのポートレートとシーン画像に「再生成（追加枠1枚）」を表示する。再生成中は二重クリックを無効にし、元画像は成功するまで保持する。
- シーン画像がある場合にも、失敗理由を画像上に表示する。保存履歴から開いた場合は保存済みの付属画像プロンプトを参照し、古い形式でプロンプトを復元できないときは再生成操作を出さない。
- 画像生成APIや日次枠の計算は変更しない。実際の画像生成は有料APIを伴うため、ローカルの検証では実行しない。
