# SEOジョブ画面の非同期処理の範囲

読込要求とポーリング中の状態をジョブIDごとに保持する。画面終了またはID変更では読込を中断し、旧ジョブの成功・失敗・完了処理が現在の画面を更新しないようにする。既存の12秒タイムアウトと応答ID検証は維持する。

自動継続は、取得したジョブのIDと現在のパラメーターが一致する場合に限る。再開要求の応答待ち中に画面を離れた場合も、続くadvance要求を送らない。既に送出した要求のサーバー処理を取り消す機能ではない。

`node scripts/security-regression/verify-seo-job-scope-mounted.cjs` は実ページと設定・公開メッセージの計3モジュールをReact/JSDOMにマウントする。遅延旧GET、画面終了、新GET待機、通常自動実行、auto=0、4種の停止状態、置換済み、レビュー待ち、新ジョブ、手動再開・離脱・拒否の18群を確認する。StrictModeで古い中断が現在の読込表示や重複抑止を解除しないことと、期限到達時のエラー表示も確認する。既存の効果単体テスト34群と読込期限25群も維持する。

ネットワークとタイマーは合成し、表示用子コンポーネントをスタブに置き換える。実HTTP・AI・DB・通知は呼ばない。ソースのハッシュと実ネットワーク要求数を `DOYA_SEO_JOB_SCOPE_EVIDENCE_DIR` または一時ディレクトリへ保存し、CIで7日間保持する。

同じページのインスタンスを保持してパラメーターを変更する条件であり、実際のNext.js画面遷移やネイティブ表示の確認は別途必要。取消確認ダイアログなど、ここで列挙していない操作の離脱条件も別の検証対象とする。
