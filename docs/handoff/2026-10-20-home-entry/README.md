# ホームの初期表示と組織入口の読取補修

ホームは取得時刻を基準にし、日本時間の挨拶・日付・予定をSSRとクライアントでそろえます。無効な日時やタイムゾーンのない日時を現在時刻に置き換えず、日付だけの予定は日本時間として扱います。従来画面にも同じ基準を使います。

SFAと商談準備の入口では、組織確認の失敗を未所属・未ログインと分けて再読み込みを表示します。利用者や認証状態が変わった後の古い読取・作成結果は反映しません。同じ認証済み利用者のsession object更新では入力と読取結果を保持し、履歴復元では再確認します。
