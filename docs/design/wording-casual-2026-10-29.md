# くだけた言い方の一覧と直し（2026-10-29）

メイン経由の指示: 本番のドヤポップアップ（/popup）に「サイトのURLを入れたら、押してね」と、くだけた言い方が残っている。全ツール（`src/app/(shell)/` 以下と共通部品）で「〜してね」「〜だよ」などを探し、一覧にして直す。ドヤくんのせりふとして意図的にくだけている所は、分けて、直すかどうかを判断できるようにする。

## 4. 気づいたこと

- 操作の案内（ドヤくんの横に出る一言）は、ほとんどのツールで「押してね」と「このまま待ってね」の同じ形だった。共通の部品 `OneButtonBar` の例文（コメント）も同じ言い方で、直しました。
- 今後、新しいツールを足すときは、案内の文を「〜してください」「〜お待ちください」の形にそろえる。
