# ドヤくんの新しい絵（格闘技・卓球・喜多方ラーメン）— Codex への依頼（2026-11-08）

本人の指示「格闘技や卓球をしているドヤくんの絵を Codex で追加してください」による依頼です。
ドヤくんの紹介ページ（`/doyakun`、PR #162）のプロフィールで使います。いまは近い絵（jump・ramen）で代用しています。

## 守ること（前回と同じ）

- 絵は **Codex の内蔵の画像生成（ChatGPT の定額枠。`auth_mode=chatgpt`、API キー無し）だけ**で作る。有料の API は使わない。
- 手本の3枚（`public/character/hello-512.webp`・`working-512.webp`・`present-512.webp`）を添付し、同じ絵柄（白いクマ・青いゴーグル・パーカー・青系の飾り）にそろえる。
- 背景は**単色の緑**（#00ff00）にして1枚ずつ作る。
- 取り込み: `python3 scripts/kun-import-pose.py <緑の背景の png> <名前>` → `public/character/<名前>-512.webp` と `-256.webp`。
- 重い処理は `~/Code/tools/pc-guard/heavy-slot.sh` を通して1つずつ回す。Mac の空きが 10GB を切ったら止める。
- 作業ブランチは `claude/modest-ritchie-ikizk7`（PR #162）。main には直接入れない。

## 作る絵（5枚）

| 名前 | 絵 | 使う場所 |
|---|---|---|
| `fight` | 格闘技の構え。オープンフィンガーグローブをはめ、ファイティングポーズで自信のあるドヤ顔 | プロフィール「しゅみ」 |
| `grapple` | 寝技の練習。**練習用の人形（グラップリングダミー）**に腕を回して極めている（ダースチョークの形）。相手は人やキャラにしない。痛そうな表情は描かない | プロフィール「とくい（ダースチョーク）」 |
| `pingpong` | 卓球のラケットを持って構える。卓球台の端と白いボール | プロフィール「しゅみ」・いろいろなドヤくん |
| `chiquita` | 卓球のチキータを打つ瞬間。台の上でバックハンド、手首をひねり、ボールに横回転の弧の線 | プロフィール「とくい（チキータ）」 |
| `kitakata` | 喜多方ラーメンを食べる。平打ちのちぢれ麺、チャーシューが丼いっぱいに並ぶ「肉そば」、朝の光（朝ラー） | プロフィール「すきなもの」 |

### 1枚ずつのプロンプト（手本の3枚を添付して使う）

共通の前置き:
> 添付の3枚と同じキャラクター（白いクマ「ドヤくん」、青いゴーグル、白いパーカーに `</>` のマーク、青系の小さな飾り）を、同じ絵柄・同じ線の太さで描いてください。全身、正方形、背景は単色の緑（#00ff00）だけ。文字は入れない。

- `fight`: 「オープンフィンガーグローブをはめて、ファイティングポーズで構えている。自信のあるドヤ顔。」
- `grapple`: 「床の上で、練習用のグラップリングダミー（顔のない布の人形）の首と片腕を両腕で抱えて、絞め技の形を練習している。真剣だけど楽しそうな表情。人形は灰色。」
- `pingpong`: 「赤い卓球のラケットを持って前傾で構えている。手前に卓球台の角、空中に白いボール。」
- `chiquita`: 「卓球台の上で、バックハンドで手首を大きくひねってボールを打った瞬間。白いボールから横に曲がる青い弧の線が出ている。」
- `kitakata`: 「チャーシューが丼いっぱいに並んだ醤油ラーメン（平打ちのちぢれ麺）を、箸で持ち上げて幸せそうに食べている。後ろに朝の光。」
