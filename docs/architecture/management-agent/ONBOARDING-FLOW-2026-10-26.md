# はじめての利用の流れと、経営ホームを「管理の画面」にする設計

2026-10-26 作成。ユーザーの依頼（メイン経由、音声入力の要約）は次の2つです。

- A: 例をたくさん出し、押すだけで入れられるようにする。経営ホームを、ここから何でもできる管理ツールのようにする。
- B: 最初のログインで、会社名や URL を登録しやすくする。その登録で、ツール全体が使いやすくなる流れにする。

この文書は、その設計と提案です。実装は、旗の内側で、段階に分けて入れます。

## 1. 今の流れ（2026-10-26 時点）

1. LP から Google でログインします。新しい人には、ドヤパワーの最初の 100 が付きます（新料金。旗 `NEW_PRICING_ROLLOUT` の内側）。
2. 経営ホーム（/home）が開きます。会社が未登録なら、「会社を登録してください」の帯が出ます。
3. 会社の登録は、窓（`src/components/shell/CompanyDialog.tsx`）で行います。項目は、会社名（必須）、サイトの URL（任意）、業種（任意）です。保存先は `AccountCompany`（name・websiteUrl・industry・logoUrl）です。
4. そのあとは、各ツールへ移ります。ツールごとに、会社名や URL をもう一度入れることが多いです。

困っている点:

- 登録しなくても使えるので、登録が後回しになりやすいです。登録した値も、ほとんどのツールで初期値に使われていません。
- 同じ会社名・URL を、ツールごとに入れ直しています（商談準備・記事・バナー・ペルソナ・見積の発行者など）。
- 最初の成果（下書きが1つできる）までが長いです。何から始めればよいかが分かりにくいです。

## 2. 目指す流れ（最初のログインから最初の成果まで、3分以内）

1. **ログインの直後に、1画面の「はじめの設定」を出します。** ようこそ（知らせの部品の (1)）の1枚目に置きます。
   - 入れてもらうのは、サイトの URL だけです。
   - 会社名と業種は、URL から読んで自動で入れます（§3）。違っていれば、その場で直せます。
   - 人数（1〜5人・6〜20人・21人以上）と、使いたいこと（マーケティング・営業・採用・経理）は、押すだけの選択にします。どちらも任意です。
   - 「あとで」でとばせます。とばした人には、はじめの手順（知らせの (2)）に「会社を登録する」が残ります。
2. **登録した値を、全ツールの初期値にします（§4）。** 「会社の情報」は1か所だけに持ち、各ツールはそこから読みます。
3. **最初の成果へ案内します。** 「使いたいこと」に合わせて、経営ホームの例のボタンとよく使う操作を並べ替えます。例: 営業を選んだ人には、「商談の準備をまとめて進めたい」を先頭にします。
4. **ドヤパワーの「100からスタート」の知らせ**（新料金の STARTER_WELCOME）は、はじめの設定のあとに出します。同時に出すのは1つだけで、順番は知らせの部品が決めます。
5. はじめの手順（会社の登録・ツールを1つ使う・ドヤくんに頼む）が全部済んだら、お祝いの知らせを1回出します。

## 3. URL から会社名・業種を自動で入れる

- サイトのトップページを1回だけ読みます。読み方は、商談準備の会社の調査（`scrapeCompanyWebsite`）と同じ、安全な取り方（`safeFetch`）です。
- タイトル・説明・会社概要の文から、会社名・業種・ひとことの説明を取り出します。
- 有料の AI を使う場合の見込み:
  - モデルは gemini-2.5-flash です（会社の調査と同じ）。
  - 1回の目安は、入力が約 5,000 トークン、出力が約 300 トークンです。1回あたり約 $0.002（約 0.3 円）です。
  - 新しい登録が月 1,000 件なら、約 $2 です。
  - 本番で動かす前に、モデル・回数・見込み額を出して、ユーザーの承認を取ります（CLAUDE.md の決まり）。
- AI を使わない案もあります。HTML の title・og:site_name・meta description・JSON-LD（Organization）だけで、会社名の多くは取れます。まずこちらで入れて、取れないときだけ AI を使う2段にすると、費用を抑えられます。
- 読んだ値は、入れる前に必ず画面で見せ、本人が「これでよい」を押してから保存します。

## 4. 登録した値を、どのツールの初期値に使うか

| ツール | 使う値 | 使い方 |
|---|---|---|
| 商談準備（shodan） | 会社名・URL・説明 | 「自社の情報」の欄に、最初から入れる |
| 記事（seo） | 会社名・URL・業種 | 記事の書き手と、自社の紹介の文の初期値 |
| バナー（banner）・広告画像 | 会社名・ロゴ・色 | ブランドキット（他社調べの 43）の素にする |
| ペルソナ（persona） | 業種・説明 | 「どんな商品か」の初期値 |
| 見積（quote） | 会社名 | 発行者の会社名の初期値（インボイス番号などは見積の設定で別に入れる） |
| スライド（doyaslide） | 会社名・ロゴ | 表紙とロゴの初期値 |
| 経営ホーム | 使いたいこと・人数 | 例のボタンとよく使う操作の並び |

- 各ツールに写しを作らず、`AccountCompany` を正本にして読みます。ツールの側で上書きした値は、そのツールの中だけで使います。
- 組織ごとの設定を持つツール（sfa・shodan・aio など）は、組織を作るときの初期値に使います。

## 5. 経営ホームを「管理の画面」にする案

経営ホームを開けば、全ツールの主な操作ができる形にします。上から次の順に並べます。

1. **ドヤくんに頼む**: ゴールの欄と、例のボタン（6つ。2026-10-26 に入れた）。
2. **よく使う操作**: 区分ごとに2つずつ、各ツールの主な操作へ1回で移るボタン（2026-10-26 に入れた）。あとで、本人がよく使うものを先に並べます。
3. **最近の作業**: 各ツールで最近作ったもの（見積書・記事・スライド・バナーなど）を、新しい順に5つ。押すとその画面が開きます。
4. **承認待ち**: 自分が承認する見積書・申請などの一覧と、件数の札。
5. **下書き**: 途中で止まっているもの（作戦の続き・保存していない見積書など）。
6. **今月の数字**: 売上と支出（今ある経営ホームの数字）と、ドヤパワーの残り。

3〜5 は、各ツールの一覧の API を読んで並べます。新しい表は作りません。読むのは本人の組織の範囲だけです（各ツールの access.ts の判定を通す）。

## 6. 段階の分け方

| 段階 | 中身 | 旗 |
|---|---|---|
| 1 | 例のボタン・よく使う操作・作戦にできない依頼のツールへの案内 | AGENT_ORCHESTRATION_ROLLOUT（済み） |
| 2 | はじめの設定（URL だけ・押すだけの選択・あとで直せる） | GUIDE_POPUPS_ROLLOUT |
| 3 | 登録した値を、商談準備・記事・ペルソナ・見積の初期値に使う | ツールごとに、GUIDE_POPUPS_ROLLOUT の内側 |
| 4 | 管理の画面の「最近の作業」「承認待ち」「下書き」 | AGENT_ORCHESTRATION_ROLLOUT |
| 5 | URL から会社名・業種を自動で入れる（AI を使う部分は承認のあと） | GUIDE_POPUPS_ROLLOUT |
