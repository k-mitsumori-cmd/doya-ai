## 決まり

- AI に保存の手段を渡さない。API `/api/agent/chat` は DB に業務データを書かない（使用回数の記録だけ）。
- 保存は、ツールの画面の本物の送信処理だけが行う。本人が確認カードか画面のボタンを押したときだけ呼ぶ。
- 完了の表示は、画面の送信処理が成功を知らせたあとだけ出す。失敗したら、失敗の内容と次にできることを出す。
- 欄に入れる値は、依頼の文から確かめられた値だけ（`groundValues`）。文に無い値は捨てて聞き返す。
- 種類・状態・開始日のような決まった値は、操作の定義（`fixed`）から入れる。AI には決めさせない。
- 計算（税、合計）は画面の今の処理のまま。
- AI のモデルは Claude Haiku 5.5（2026-11-06 本人の決定。Opus と Sonnet はチャットとエージェントに使わない）。1依頼 最大 約0.2円。
- ドヤパワーは減らさない。1人1日30依頼、全体1日300依頼（`consumeDailyQuota`）。聞き返しは AI を呼ばない。
- 旗は `AGENT_CHAT_ROLLOUT`（off / preview / all、既定 off）。off のときは今の画面と API が今のまま動く。
- 動きは位置と透明度が中心で、1つ 0.2〜0.5 秒。`prefers-reduced-motion` では飛ぶ値とカーソルを出さない。動きは実際の処理に合わせる。
- 売上の追加は単発の契約（`/income/contracts/new`、type=one_time、status=active、開始日は今日）。月の売上は `IncomeRevenueSchedule` から計算するので、手入力の請求書では月の売上に入らない。
