# 操作イメージの画面切り替え（2026-09-08）

対象：総合トップと17サービスのLP。各サービスの3画面、合計51画面をコードで描画し、4.2秒ごとに切り替える。トップはバナー・商談準備・スライドの3画面ずつを紹介する。

カーソル移動、クリック波紋、対象欄の強調、SEO・プロマネ・スライドの入力演出を追加。表示するモックは既存のサービス説明用画面。実際のAI実行・送信・アカウント操作は発生しない。

ステップ選択で一時停止し、再生で再開する。拡大中は対象の画面を固定。全体表示と原寸表示、Escapeによる終了とフォーカス復帰を維持。ページの停止ボタン、OSの動き軽減、画面外・非表示タブでの停止にも対応する。動きを止めた場合、入力文字は全文表示する。

画面は560×340の座標系で描画し、縦長の内容は枠内に縮小する。サービスごとに遅延読み込みし、読込失敗時には再試行できる。画面内部は操作できない説明図としてアクセシビリティツリーから除外し、現在のステップの代替説明を提供する。
