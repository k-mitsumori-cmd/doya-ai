# ドヤバナーAI シネマティックFV

対象は `/banner` の未ログイン向けLP、および `/banner/landing`。総合トップ・他サービスのFVは今回変更していない。

## 設計と制作

参考投稿の24秒の映像をChromeで確認。接写から全景へのスケール変化、余白、光と影を参考に、ドヤくんが広告作品を生み出すアトリエを新規に画像生成した。詳細な指示・生成経路は [image-prompt.md](image-prompt.md)。

- 新しい画像は1672×941のWebP、169,218 bytes。
- 2.6秒のズームアウト、見出し・CTAの段階的な登場、スクロールに合わせた小さな奥行き変化。
- スマホは作品とドヤくんを上、見出しとCTAを下に配置。
- 生成画像はコンセプトビジュアルと明記。製品を実行して得られた出力としては表示しない。
- 既存の3段階の操作デモをFVの次に配置。選択・自動再生・拡大表示を維持。
- 動きの停止、再開、演出の再実行、OSのモーション軽減に対応。

## 比較

`/renewal-comparison/banner-cinematic.html` は左に保存済みの旧版画像、右に現在のLPを埋め込んで全体比較する。旧版は9月7日のリニューアル前と、9月8日のFV変更前から選択できる。PC幅1440px、スマホ幅390pxで表示し、枠内に縮小する。左右は別々にスクロールできる。

9月8日の4つの既存画像を `public/renewal-comparison/archive/20260908/` にコピーして保持した。従来の比較ページ・元のbefore画像・9月8日の録画も維持。既存比較ページから新しい全体比較へリンクした。既存録画の説明には9月8日時点と明記した。

埋め込み対象の公開LP `/banner/landing` のみ、同一オリジンからの表示を許可するヘッダーを追加（X-Frame-Options: SAMEORIGIN / CSP: frame-ancestors 'self'）。アプリ・認証画面などには従来のDENYを維持。

## 検証

- DB更新をスキップしたNext.js本番ビルド成功。
- TypeScript `tsc --noEmit` 成功。
- 変更したTSXに対するESLint成功。
- ブラウザで320 / 390 / 760 / 1024 / 1440pxを確認。画像読み込み、見出し1件、本文の横はみ出しなし（responsive.json）。
- 操作デモへのアンカー移動、2番目の画面への切り替え、拡大ダイアログ、Escapeで閉じる、全体の動きの停止を確認。
- モーション軽減はCSSとイベント分岐を確認。OS設定を切り替えた実機テストは行っていない。

公開状態は publication.json の確認記録を参照。
