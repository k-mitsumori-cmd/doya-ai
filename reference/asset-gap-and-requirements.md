- 公開中サービスは 17件。`HIDDEN_SERVICE_IDS` に 14件（提供終了・実体なし・adimage統合）が入っており、対外露出はしていない。

### 1-7. 配信パフォーマンス（画像起因）

- `src/components/lp/DoyaKun.tsx` が **生の `<img>`** でマスコットを配信。`public/character/*.png` は 816×816・約800KB。Hero では 132px 表示なのに `priority`（eager）で読み込むため、LCP要素が約800KBの未最適化PNGになっている。
- ロゴPNGが 1.3MB〜3.8MB（`banner/logo.png` は 3.8MB / 2048×2048）。`next/image` 経由なので配信は最適化されるが、原本が重くビルド・変換コストが高い。
- ロゴのアスペクト比が **2048×2048（正方形）と 2016×864（横長）の2系統混在**。`ToolSwitcherMenu` のコメントにも「アスペクト比がバラバラ」と明記されており、揃え直しが必要。

### 1-8. ブランド表記のゆれ

- 旧ブランド紫 `#7f19e6` がソース内に **508箇所** 残存。`ToolSwitcherMenu` のアクティブ時フォーカスリングなど、共通コンポーネントにも残っている。
- `public/site.webmanifest` の `theme_color` が `#3B82F6`。ブランド青 `#0066ff` と不一致。

### 1-9. 信頼要素のビジュアルが無い

導入事例・お客様の声・実績数値・受賞/掲載ロゴなど、B2B LPで効くビジュアルが17サービス全てで未整備。

### 1-9b. アイコン体系の破綻（新規発見）

**① 本番のファビコンが図形として崩れている（実害あり）**

`https://doya-ai.surisuta.jp/icon` を実取得して確認。`src/app/icon.tsx` が生成する「青角丸＋ロケット＋AI」のロケット図形が **分断して破片状にレンダリングされている**。さらに "AI" の文字が左下隅に寄っており構図が破綻。ブラウザタブ・ブックマーク・検索結果に出る一番小さい面積で、これが配信され続けている。

**② ファビコンとPWAアイコンが別のブランドになっている**

| 面 | 実体 | 絵 |
|---|---|---|
| `src/app/icon.tsx`（favicon / 512） | 動的生成 | 青角丸＋ロケット＋AI（崩れている） |
| `src/app/apple-icon.tsx`（180） | 動的生成 | 同系 |
| `public/icon-192x192.png` / `icon-512x512.png`（PWA） | 静止PNG | **白クマのキャラクター**（VRゴーグル・コード窓） |

同じサービスのアイコンとして、ロケットと白クマという無関係な2つが同時に配信されている。

**③ PWAアイコンが maskable セーフゾーンを無視している**

`site.webmanifest` は 192/512 とも `"purpose": "any maskable"`。しかし実素材は余白ゼロで端まで絵が伸びているため、Android のマスク適用時に **耳と手が確実に切れる**。maskable は中央80%（512pxなら直径409pxの円内）に主要素を収める必要がある。

**④ アイコンライブラリが2系統併存し、専用SVGセットが無い**

- `lucide-react` を import しているファイル: **237**
- Material Symbols / `<Sym>` を使っているファイル: **171**
- 自前の `icons.tsx` に相当するファイル: **0件**

CLAUDE.md のUI規約は「Material Symbols Outlined」だが、実態は Lucide の方が広く使われている。同じ意味に別の絵が当たっており、サービスをまたぐと印象が揃わない。

**⑤ UI内の絵文字が134ファイルに残存**

グローバル規約「UIに絵文字アイコンを使わない（AIっぽさの主因）」に反する。出現数の多い順:

| ✨ | 34 | 📊 | 22 |
| 💡 | 33 | 👤 | 20 |

**⑥ サービス別ファビコンが無い**

`src/app/icon.tsx` はルート1本のみ。17サービスのどれを開いてもタブのアイコンが同じで、複数ツールを並べて開いたときに見分けられない。

**⑦ 空状態（empty state）のイラストが無い**

「まだ生成結果がありません」等の画面が全サービスでテキストのみ。

## 3. 制作依頼用 要件定義リスト

### 3-0. 全アセット共通の規約

- **絵文字を使わない**（UI・画像内とも）。アイコンは Material Symbols Outlined か専用SVGのみ。
- **日本語テキストを画像に焼き込まない**。AI生成画像は日本語の字形が崩れる。文字はコード側（HTML/SVG）で後乗せする。ロゴのロゴタイプのみ例外で、必ず目視検品する。
- 人物を描く場合は **East Asian（日本人・韓国系）の顔** を明示指定する。
- ブランド青 `#0066ff` を基調。アクセントは `#ff1e72` / `#ffd400` / `#00e0ff` / `#009bff` から1色。
- 生成は `src/lib/image-generator.ts` の `generateImageWithFallback()` 経由（gpt-image-2 → nano-banana-pro-preview）。直接API呼び出しは禁止。
- gpt-image-2 の寸法制約: **16の倍数**・アスペクト比 3:1 以内・最大 3840px。9:16 は `1152x2048`。

### 3-8b. ブランドアイコン刷新（`B-01`／1式・最優先）

現行のファビコンが崩れている以上、これは「あれば良い」ではなく**修理**。

| 項目 | 仕様 |
|---|---|
| 成果物 | マスターSVG 1点 ＋ 書き出し PNG（16 / 32 / 180 / 192 / 512 / 1024） |
| デザイン | ロケットと白クマのどちらをブランドの顔にするか**先に決める**。決めた側に一本化し、もう一方は廃止する |
| 制約 | 16px で判別できること。線は2px相当以上、要素は3つまで、文字は入れない（現行の "AI" は削る） |
| maskable | 主要素を中央80%（512pxなら直径409pxの円内）に収める。周囲はベタ塗りで埋める |
| 配置 | `public/icon-192x192.png` / `icon-512x512.png` を差し替え、`src/app/icon.tsx` / `apple-icon.tsx` を**同じマスターSVGから描く**ようにする（現状は別デザインが動的生成されている） |
| 検品 | Chrome タブ / Safari ブックマーク / Android ホーム画面（マスク適用）/ iOS ホーム画面 の4面で目視 |
| 併せて | `site.webmanifest` の `theme_color` を `#0066ff` に（F-06） |

| 項目 | 仕様 |
