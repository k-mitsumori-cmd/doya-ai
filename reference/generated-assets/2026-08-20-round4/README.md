# 第4弾 ロゴ規格合わせ 制作メモ（2026-08-20）

依頼書: `reference/asset-request-round4.md`
要件の正本: `reference/asset-gap-and-requirements.md`（`L-xx`）

## 完了したこと

### R4-A-2 横長8点の軽量化（規格達成）

`hr / doyalist / doyaslide / cunning / promane / sfa / shodan / aio`

寸法は元から 2016×864 のため無変更。パレット量子化のみで容量を落とした。

| 設定 | 値 |
|---|---|
| エンコード | `sharp().png({ palette: true, colors: 128, quality: 60, effort: 10, dither: 0 })` |
| 結果 | 1.3〜1.8MB → **81〜139KB**（上限150KB以内） |
| 透過 | 全点で保持 |

`dither: 0` が効く。ディザを効かせると 160KB を下回らなくなる（ハーフトーンの網点が
ノイズとして符号化されるため）。目視ではバンディングは出ていない。

### kintai の寸法統一

1254×480（2.61:1）→ 2016×864（2.33:1）。絵を歪めないよう `fit: 'contain'` で
中央配置し、余白は透過のまま。346KB → 40KB。

### 正方形4点の軽量化のみ（寸法は未達）

`banner / seo / interview / persona`

絵柄・寸法は無変更で容量だけ削減。2.6〜3.8MB → **170〜227KB**。
上限150KBは超えているが、正方形のまま詰めるのはここが限界。横長化と同時に解消する。

### logo.webp は作らない判断

作って計測したところ、**WebPの方がパレットPNGより大きい**（hr: PNG 93KB / WebP 149〜187KB）。
フラットな線画＋透過はパレットPNGが最も効率がよい。加えて `logo.webp` はコードから
**1箇所も参照されていない**（配信時の変換は `next/image` が行う）。
今回作った8点は破棄した。既存4点（mensetsu / quote / aishodan / adimage）は
そのまま残置してある（未参照）。

## できなかったこと: R4-A-1 正方形4点の横長化

`scripts/round4-square-logos.ts` で、既存ロゴを参照画像として
`generateImageWithFallback()`（`background: 'transparent'`）に渡し、
2016×864 の横長構図へ再構成を試みた。出力は `square-to-wide/` に保存。

**4点とも本番へは採用しなかった。** 実際に使われたモデルは `gpt-image-1`
（`gpt-image-2` は編集に未対応でフォールバック）。

| サービス | 結果 | 不採用の理由 |
|---|---|---|
| banner | **破綻** | ロゴタイプが「ドヤバナーAI」→「ドヤバー・A」に欠落。バッジの輪郭も途切れ、パネル内の日本語も判読不能 |
| persona | **不可** | 文字は正しいが**透過が効かず全面ベタ塗り**。左端が切れ、配色が旧紫（#7C3AED系）へ寄った |
| seo | 要修正 | 文字は正しく透過も効いたが、「ドヤ」が暗色で描かれ濃紺のバッジに沈む。ゴーグルの `><` モチーフが消失 |
| interview | 要検討 | 文字・透過・構図は良好。ただし配色がオレンジ＋くすんだ青へドリフトし、ブランド青から外れた |

### わかったこと

- 参照画像つきの再構成では、**日本語ロゴタイプの保持は運任せ**。4点中1点は完全に破綻した
- 配色とゴーグルのモチーフは、プロンプトで固定を明示しても保持されない
- `background: 'transparent'` を渡しても、透過にならない出力が混じる

### 次にとるべき手

生成AIでの一括再構成は品質が安定しないため、次のいずれかを推奨する。

1. **ロゴタイプを画像生成に含めない。** 白クマ＋モチーフだけを横長で生成し、
   日本語ロゴタイプは既存ロゴから切り出して合成する（字形が絶対に崩れない）
2. 人の手で4点だけ横長へ組み直す（既存の絵素材はそのまま使える）

いずれも `square-to-wide/` の出力を下敷きにできる。

## 退避

差し替え前の原本13点を `legacy-logos/` に保存（26MB）。削除していない。
