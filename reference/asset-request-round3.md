## 1. 依頼 R3-A: バナー見本サムネイル 31点の作り直し

`public/banner-samples/` の31点が、**中身のない汎用グラデーションのプレースホルダ**のまま本番で使われています。

- 内訳: カテゴリ12点 / 目的7点 / サイズ12点
- 使用箇所: `banner/dashboard/create`（ユーザーがカテゴリ・目的・サイズを選ぶ画面）、`api/seo/template/image/category/[category]`、`api/swipe/question-images` ほか
- 問題1: **バナー生成サービスの見本なのに、バナーになっていない。**どんな成果物が出るのか選択時に伝わらない
- 問題2: 配色が旧パレット。使用色の上位は `#7C3AED`（紫）`#2563EB` `#FBBF24` `#06B6D4` で、**ブランド青 `#0066ff` が1つも入っていない**

| 項目 | 仕様 |
|---|---|
| 対象 | `cat-*.svg` 12点 / `purpose-*.svg` 7点 / `size-*.svg` 12点 |
| 寸法 | 現行と同じ 1200×628（`size-*` はそのサイズ比を表す図なので現行寸法を維持） |
| 形式 | WebP（現行SVGから差し替え。ファイル名は据え置き、拡張子変更時は参照5箇所を更新） |
| 容量 | 各 80KB 以下 |
| 内容 | **実際にそのカテゴリ・目的で生成されうるバナーの見本**にする。カテゴリは業種の雰囲気、目的は用途（LPヒーロー / SNS広告 / ウェビナー等）が判別できる構図 |
| 文字 | 日本語を焼き込まない。ダミー文字を入れる場合は判読不能なレベルの抽象化に留め、選択肢のラベルはUI側で出す |
| 配色 | ブランド青 `#0066ff` を基調。アクセントは `#ff1e72` / `#ffd400` / `#00e0ff` / `#009bff` から1色 |
| 優先 | **P0**（ユーザーが最初に触る選択画面のため） |

`size-*` の12点だけは性質が異なります。サイズ比較図なので、写真的な見本ではなく **比率が一目で分かる図版**として作り直してください（正方形・縦長・横長・バナー帯などの違いが伝わること）。

## 4. 依頼 R3-D: 導入事例・お客様の声 — 着手前に判断が必要

要件書では未整備として挙げていますが、**実在の導入企業・利用者の声が無い状態で作ることはできません。**
捏造した実績・架空のロゴ・存在しない顧客の写真を置くことは、景表法上も信頼上も不可です。

判断していただきたいこと:

| 選択肢 | 内容 |
|---|---|
| A | 実在の利用企業・利用者がいる → 掲載許諾を取ったうえで、社名ロゴまたは匿名表記（業種・規模のみ）で構成する |
| B | まだ無い → **このセクション自体を作らない。**代わりに「使い方の具体例」「想定シーン」として、事実として書ける内容に置き換える |
| C | 自社実績を使う → 株式会社スリスタ／SaaSは死にましぇんでの自社利用実績を一次情報として出す |

C は現実的で、かつ一次情報として強い選択肢です。指示をいただければ内容を整理します。

## 5. 共通規約（全アセット）

- 絵文字を使わない（UI・画像内とも）
- 日本語テキストを画像に焼き込まない。文字は HTML / SVG 側で後乗せ
- 人物は East Asian（日本人・韓国系）の顔を明示指定
- 基調は `#0066ff`。アクセントは `#ff1e72` / `#ffd400` / `#00e0ff` / `#009bff` から1色
- 画像生成は `generateImageWithFallback()` 経由（直接API呼び出しは禁止）
- gpt-image-2 は 16の倍数・アスペクト比3:1以内・最大3840px
- **透過が要る用途は `background: 'transparent'` を明示的に渡す。**既定は不透過（人物画像の切り抜き事故を防ぐため 2026-08-20 に変更）
- アイコンは `lucide-react` を正本とし `src/components/icons.tsx` のラッパーを使う。LPキット内の Material Symbols は凍結
