# 新サービス公開チェックリスト

新しいサービスを追加したとき、これを上から順に確認する。
**新4サービス（quote / aishodan / adimage / mensetsu）で、ここに挙げた項目が
ほぼ全て抜けていた実績がある。** 抜けても型チェックもビルドも通るので気づけない。

## A. 見つけてもらう（SEO / LLMO）

- [ ] **A1. `layout.tsx` に `buildServiceMetadata()` がある**
  - ⚠️ 無いと canonical がルートlayoutの既定（サイトトップ）のままになり、
    検索エンジンからは「トップページの重複」に見えて一切拾われない。
  - 確認: `curl -s <URL> | grep canonical` が自ページを指すこと
- [ ] **A2. `<title>` がサービス固有**（`ドヤマーケAI | AI SaaSサービス群` のままでない）
- [ ] **A3. `LpJsonLd` で構造化データを出している**（FAQ含む）
- [ ] **A4. sitemap に載る**（`services.ts` に登録し、`HIDDEN_SERVICE_IDS` に入れない）
- [ ] **A5. サブページに `buildServiceSubMetadata()`**（料金など。親のtitleを継ぐと指名検索でLPより上に出る）

## B. 伝わる（LP）

- [ ] **B1. 未ログインの方に見せるLPがある**
  - ⚠️ 「ログインが必要です」の箱だけだと、何をするサービスなのか説明する面が無い。
- [ ] **B2. 構成が標準の順になっている**
  ヒーロー → 課題 → 機能ショーケース → 手順 → 選ばれる理由 → FAQ → 最終CTA
- [ ] **B3. ヒーローのCTAは2個まで**（国内BtoB SaaS 15本すべてで2個が上限）
- [ ] **B4. CTA直下に摩擦を消す但し書き**（「クレジットカードの登録は不要です」等）
- [ ] **B5. 製品モックがある**（画面の様子。文字だけのLPにしない）
- [ ] **B6. 実績数値を捏造していない**
  - ⚠️ 導入社数・継続率・No.1 は、出典と時点を併記できないなら**書かない**（優良誤認）
- [ ] **B7. 絵文字を使っていない**（専用SVG / Material Symbols のみ）

## C. 使い始められる

- [ ] **C1. 未ログインと「組織なし」を区別している**
  - ⚠️ 区別しないと、未ログインの人に組織作成フォームを見せることになり、
    押しても401で何も起きない画面になる。
- [ ] **C2. 料金ページがある**（`services.ts` の `pricingHref` が自分自身を指していない）
- [ ] **C3. 共通ヘッダー（`ServiceTopBar`）が入っている**
  - ⚠️ 無いと他のツールへ移れず、トップへ戻る導線も無い。
- [ ] **C4. ツール切替のアイコンが登録されている**（`ToolSwitcherMenu` の `SERVICE_ICON_MAP`）
- [ ] **C5. ゲスト画面にヘッダーが出ない**（応募者・見込み客に自社サービス一覧を見せない）

## D. 約束を守る（宣言と実装のズレ）

- [ ] **D1. `services.ts` の `features` が全て実装されている**
- [ ] **D2. `pricing.free.limit` の上限が実際に効いている**（`assertFreeLimit` 等）
- [ ] **D3. `requiresAuth` が実態と合っている**
- [ ] **D4. 実装したAPIが画面から呼ばれている**
  - ⚠️ 「APIはあるが画面から呼ばれず、機能が存在しないのと同じ」が繰り返し起きている。

## E. 壊れない

- [ ] **E1. `[id]` 系APIが `findFirst({ where: { id, organizationId } })` の二重条件**
- [ ] **E2. 未認証で叩ける経路の返却がホワイトリスト化されている**
- [ ] **E3. AI生成・画像生成のルートに `maxDuration = 300`**
  - ⚠️ 無いとVercelの既定で打ち切られ、**本番でだけ**504になる。
- [ ] **E4. PDF生成なら `next.config.js` の `outputFileTracingIncludes` に追加**
  - ⚠️ ローカルでは動くので気づけない。**本番でだけ**500。
- [ ] **E5. 参照している静的アセットが `public/` に実在する**
- [ ] **E6. 失敗しても復旧手段がある**（一度きりで失敗すると詰む操作を作らない）

- [ ] **F1. `HIDDEN_SERVICE_IDS` に登録**
