## 0. 依頼の範囲

公開17サービスのうち、ロゴが **2048×2048 の正方形**のまま残っている4点を
**2016×864 の横長**へ組み直す。

| サービス | 現行 | 現行容量 | 目標 |
|---|---|---|---|
| banner（ドヤバナーAI） | 2048×2048 | 207KB | 2016×864 / 150KB以下 |
| seo（ドヤ記事作成） | 2048×2048 | 180KB | 同上 |
| interview（ドヤインタビュー） | 2048×2048 | 170KB | 同上 |
| persona（ドヤペルソナAI） | 2048×2048 | 227KB | 同上 |

残り13点は第4弾で規格達成済み（81〜139KB）。この4点だけが未達。

### なぜ直すか

`src/components/ToolSwitcherMenu.tsx` は高さ80pxの `object-contain` でロゴを表示する。
横長（2016×864）は幅187pxで描画されるのに対し、正方形は幅80pxにしかならない。
同じツール切替メニューの中で、この4件だけが小さく見える。

## 1. 制作方式 — ロゴタイプは生成しない

**⚠️ これが今回の依頼の核心。**第4弾で「既存ロゴを参照画像として渡し、丸ごと横長に
再構成する」方法を試し、4点とも不採用になった。

| サービス | 第4弾の結果 |
|---|---|
| banner | ロゴタイプが「ドヤバナーAI」→**「ドヤバー・A」**に欠落。バッジ輪郭も途切れ |
| persona | 文字は正しいが**透過が効かず全面ベタ塗り**。左端が切れ、配色も崩れた |
| seo | 文字・透過はOKだが「ドヤ」が暗色で描かれ濃紺バッジに沈んだ |
| interview | 文字・透過・構図は良好だが、配色がブランド青から外れた |

判明したこと。

- **日本語ロゴタイプの保持は運任せ。**4点中1点は完全に破綻した
- 配色とゴーグルの `><` モチーフは、プロンプトで固定を指示しても保持されない
- `background: 'transparent'` を渡しても透過にならない出力が混じる

そこで今回は **文字を生成対象から外す。**

### 手順

```
① 既存ロゴ（2048×2048）から「日本語ロゴタイプ」部分を切り出す
   → 画素をそのまま使うので字形は絶対に崩れない
② 白クマ＋モチーフ＋バッジ背景だけを横長で用意する
   （既存ロゴからの切り出し・再配置で足りるならそれを優先。
     足りない部分だけを生成で補う）
③ ①と②を 2016×864 のキャンバス上で合成する
   左: 白クマ＋モチーフ ／ 右: ロゴタイプ
④ パレット量子化して 150KB 以下に落とす
```

④ の設定は第4弾で確定済み。そのまま使う。

```js
sharp(input).png({ palette: true, colors: 128, quality: 60, effort: 10, dither: 0 })
```

`dither: 0` が要点。ディザを効かせるとハーフトーンの網点がノイズとして符号化され、
どう詰めても160KBを切れない。

### 生成を使う場合の制約

- 必ず `generateImageWithFallback()` 経由（直接API呼び出しは禁止）
- 透過が要るので `background: 'transparent'` を明示する（既定は不透過）
- **プロンプトに日本語を含めない。**文字は合成で入れる
- 実際に動くのは `gpt-image-1`（`gpt-image-2` は画像編集に未対応でフォールバックする）

## 3. タグラインを外す理由

**訂正**: 第4弾の依頼書では「タグラインが入っているのは banner だけ」と書いたが、
実際は **banner と persona の2点**に入っている。

外す理由は3つ。

1. 他15サービスのロゴにタグラインが無く、統一されていない
2. ロゴは小サイズでも使う。ツール切替メニューの80px高では読めず、潰れたノイズになる
3. 文言が必要ならHTML側で出せる（画像に日本語を焼き込まない原則にも沿う）

## 4. 完成条件

| 項目 | 条件 |
|---|---|
| 寸法 | 2016×864（全4点） |
| 形式 | PNG・背景透過 |
| 容量 | **150KB以下** |
| ロゴタイプ | 既存の字形と一致していること。**1文字でも欠け・変形があれば不採用** |
| 白クマ | 同一キャラクター。ゴーグルの `><` モチーフを保持 |
| 余白 | バッジが上下左右で切れていないこと |
| 並び | `ToolSwitcherMenu` を開き、17件が同じ高さ・同じ幅感で並ぶことを目視 |
| logo.webp | **作らない。**パレットPNGより大きく（93KB vs 149KB）、コードからも参照されていない |

## 5. 判断が要る点

着手前に決めていただきたいことが1つあります。

**`interview`（オレンジ／赤系）と `persona`（紫／マゼンタ系）の配色を、
横長化のついでにブランド青へ寄せるか。**

| 選択肢 | 内容 |
|---|---|
| A | **配色はそのまま**。今回は寸法だけを直す。既存ユーザーの見え方が変わらない |
| B | ブランド青系へ寄せる。17件の並びは揃うが、2サービスの印象が変わる。特に persona の紫は旧ブランド `#7f19e6` に近く、置換方針とは逆行している |

作業量は A の方が小さく、リスクも低いです。ただし B にしないと、
「旧紫を置換する」という進行中の方針とロゴだけが食い違ったまま残ります。
